## Introduction
This guide explains how to complete the sixth stage of TIS-100 AKA segment 30647

## Segment 22800
The goal for this segment is:
1. Read values from `IN.A` and `IN.B`
2. Write the lesser value to `OUT`
3. Write the greater value to `OUT`
4. Write `0` to end the sequence

## Explanation

### Command node 2

```bash
S: MOV UP, ACC
   MOV ACC, RIGHT
   MOV ACC, RIGHT
```

S:
1. This moves the value from `port UP` to the `ACC`, effectively 'saving' it
2. Move the value from the `ACC` to `port RIGHT` AKA command node's 3 `port LEFT`
3. Move the value from the `ACC` to `port RIGHT` AKA command node's 3 `port LEFT`

![final solution part 1](assets/posts/post18/post18_img3_solP1.png)

### Command node 3

```bash
S: MOV UP, ACC
   SAV
   SUB LEFT
   JGZ X
   SWP
   MOV ACC, DOWN
   MOV LEFT, DOWN
X: SWP
   MOV LEFT,DOWN
   MOV ACC,DOWN
```

S:
1. Move the value from `port UP` to the `ACC`
2. Save the value of the `ACC` to the `BAK`
3. Subtract the value of `port LEFT` from the `ACC`
4. Run `X` if the value of the `ACC` is greater than zero. This means that the value of `IN.A` is greater than `IN.B`.
5. Swap the value in `ACC` with `BAK`. This gives us back the original value of the `ACC`
6. Now move the value of `ACC` to `port DOWN`

X:
1. Move the value of `port LEFT` to `port DOWN`
2. Move the value of `ACC` to `port DOWN`


![final solution part 1](assets/posts/post18/post18_img4_solP2.png)

### Command node 11

```bash
S: MOV UP, DOWN
   ADD 1
   JRO ACC
   JMP S
   JMP Z
Z: MOV O, DOWN
   SUB 2
```

S:
1. Move the value from `port UP` to `OUT`
2. Add 1
3. Execute the instruction at offset `ACC`. If `ACC` is `1`, it will execute the next line. If it is `2` it will run `JMP Z`
4. This causes the instructions to go back to the first line of `S` which is `MOV UP, DOWN`
5. This causes the set of instructions belonging to `Z` to run

If `ACC` is `2`, JRO will run `JMP Z`

Z:
1. Write `0` to `OUT`
2. Subtract `2` from the `ACC`
