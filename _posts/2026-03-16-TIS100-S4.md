## Introduction
This guide explains how to complete the third stage of TIS-100 AKA segment 21340

![menu](assets/posts/post16/post16_img1_menu.png)

## Segment 21340
The goal for this segment is:
1. Read a value from `IN`
2. Write `1` to `OUT.G` if `IN` > `0`
3. Write `1` to `OUT.E` if `IN` = `0`
4. Write `1` to `OUT.L` if  `IN` < `0`
5. When `1` is not written, write `0` to the respective `OUT`

![solution](assets/posts/post16/post16_img2_finsol.png)

## My explanation

### Moving the values down
This moves the value from `IN` to the command node for `OUT.G`

![solution part 1](assets/posts/post16/post16_img3_solP1.png)


### First IF condition

```bash
START:
 MOV LEFT, ACC
 JGZ LARGER_ZERO
 JMP DEFAULT 
```
1. This is the label for this set of instructions which runs automatically
2. This moves the value from `port LEFT` to the `ACC`
3. If the value of `ACC` is larger than zero, run the set of instructions belonging to label `LARGER_ZERO`
4. If the value of `ACC` is not larger than zero, line 3 is skipped and line 4 is ran which runs the set of instructions belonging to label `DEFAULT`

```bash
LARGER_ZERO:
 MOV 1, DOWN
 MOV ACC, RIGHT
 JMP START
```
1. Label for this set of instructions
2. Writes the value `1` to `OUT.G`
3. Moves the value in the `ACC` to `port RIGHT`
4. Run the set of instructions belonging to label `START`

```bash
DEFAULT:
 MOV ACC, RIGHT
 MOV 0, DOWN
 JMP START
```
1. Label for this set of instructions
2. Moves the value in the `ACC` to `port RIGHT`
3. Writes the value `0` to `OUT.G`
4. Run the set of instructions belonging to label `START`

![solution part 2](assets/posts/post16/post16_img4_solP2.png)


### Second IF condition

```bash
START:
 MOV LEFT, ACC
 JEZ EQUAL_ZERO
 JMP DEFAULT
```

1. This is the label for this set of instructions which runs automatically
2. This moves the value from `port LEFT` to the `ACC`
3. If the value of `ACC` is equal to zero, run the set of instructions belonging to label `EQUAL_ZERO`
4. Run the set of instructions belonging to label `DEFAULT`


```bash
EQUAL_ZERO:
 MOV 1, DOWN
 MOV ACC, RIGHT
 JMP START
```

1. Label for this set of instructions
2. Writes the value `1` to `OUT.E`
3. Moves the value in the `ACC` to `port RIGHT`
4. Run the set of instructions belonging to label `START`

```bash
DEFAULT:
 MOV ACC, RIGHT
 MOV 0, DOWN
 JMP START
```
1. Label for this set of instructions
2. Moves the value in the `ACC` to `port RIGHT`
3. Writes the value `0` to `OUT.E`
4. Run the set of instructions belonging to label `START`

![solution part 3](assets/posts/post16/post16_img5_solP3.png)


### Third IF condition

```bash
START:
 MOV LEFT, ACC
 JLZ LESSER_ZERO
 JMP DEFAULT
```

1. This is the label for this set of instructions which runs automatically
2. This moves the value from `port LEFT` to the `ACC`
3. If the value of `ACC` is lesser than zero, run the set of instructions belonging to label `LESSER_ZERO`
4. Run the set of instructions belonging to label `DEFAULT`

```bash
LESSER_ZERO:
 MOV 1, DOWN
 JMP START
```

1. Label for this set of instructions
2. Writes the value `1` to `OUT.L`
3. Run the set of instructions belonging to label `START`

```bash
DEFAULT:
 MOV 0, DOWN
 JMP START
```
1. Label for this set of instructions
2. Writes the value `0` to `OUT.L`
3. Run the set of instructions belonging to label `START`
