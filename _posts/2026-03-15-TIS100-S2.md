## Segement 10981
The goal for this segment is to take a value from `IN.A` , double it and write it to `OUT.A`:

![goal](assets/posts/post14/post14_img2_10981.png)

## Plan 1
My initial plan is to store the value from `IN.A` into `ACC`. Afterwards, i will save the value from the `ACC` into `BAK`. This will give me two copies of the same value which allows me to double its value. Lastly, i will write the value from `BAK` into the `DOWN` port.

## Testing Plan 1
I first tested it with these two lines to verify it works:

```bash
MOV UP, ACC
SAV
```

![test1](assets/posts/post14/post14_img3_test1.png)


The first line moves the value from the `UP` port into `ACC` while `SAV` saves the value from `ACC` into `BAK`. This was also explained in the guide:

![SAV from guide](assets/posts/post14/post14_img4_SAVguide.png)

## Plan 1 fail

Afterwards, i realised it was not possible to somehow add two values in the same node as i can't directly reference BAK. So running this is not allowed:

```bash
MOV UP, ACC
SAV
ADD BAK
```

This was also stated on the guide:

![BAK from guide](assets/posts/post14/post14_img5_BAKNo.png)

## Plan 2
My second plan was to take the value from `IN.X` and save it to the `ACC` on command node 2. Afterwards, the value from `ACC` will be passed to command node 6. Command node 6 will then save it to its own respective `ACC`.  Afterwards the value of the `ACC` from command node 2 will be passed to command node 6. This gives us two instances of the same value. Command node 6 will then add this value which is the same as the one in its `ACC` to its own `ACC`, hence doubling the value. 

## Testing plan 2
I ran the following commands to test if this will work:

![test2](assets/posts/post14/post14_img6_test2.png)

Commands for command node 2:

```bash
MOV UP, ACC
MOV ACC, DOWN
MOV ACC, DOWN
```
This adds the value from port `UP` into the `ACC`. Afterwards, the value from `ACC` is moved down twice. 

Commands for command node 6:

```bash
MOV UP, ACC
ADD UP
SAV
```
This adds the value from port `UP` into its `ACC` twice. Afterwards, this value is then saved into the `BAK`.
