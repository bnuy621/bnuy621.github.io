## Introduction
Breif guide to setting up environment to code in assembly on vscode.


## Installing NASM
Ensure NASM is installed on your system. If you're running linux, run this command:

```bash
whereis nasm
```


## Extensions
Download the following extension

NASM x86_64 syntax highlighting

## Setting up environment
In the directory where you plan to store your `.asm` files. Create the folder `.vscode`


### Tasks.json

```yaml
{
    "version": "2.0.0",
    "tasks": [
        {
            "label": "Assemble and Link",
            "type": "shell",
            "command": "nasm -f elf64 -g -F dwarf ${file} -o ${fileBasenameNoExtension}.o && ld ${fileBasenameNoExtension}.o -o ${fileBasenameNoExtension}",
            "group": {
                "kind": "build",
                "isDefault": true
            },
            "presentation": {
                "reveal": "always",
                "panel": "shared",
                "clear": true
            },
            "problemMatcher": []
        }
    ]
}
```

### launch.json

```yaml
{
    // Use IntelliSense to learn about possible attributes.
    // Hover to view descriptions of existing attributes.
    // For more information, visit: https://go.microsoft.com/fwlink/?linkid=830387
    "version": "0.2.0",
    "configurations": [
        
        {
            "type": "by-gdb",
            "request": "launch",
            "name": "Launch(gdb)",
            "program": "${fileBasenameNoExtension}",
            "cwd": "${workspaceRoot}"
        }
    ]
}
```

## Running the code

Go to your .asm file and `Ctrl Shift B` to build it.

Afterwards, 2 files with `$filename.o` and `$filename` will appear:


![](assets/posts/ASM/setup/img3.png)

  
## Debugging
Ensure the output files from earlier exist first. Set a breakpoint on your code (you should see a red dot) and press Launch on the debug panel.

![](assets/posts/ASM/setup/img4.png)
