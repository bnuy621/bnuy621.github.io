## How to make a loop
A loop consists of a counter, a conditional jump and the code that is supposed to run per loop. 

### Example
```
section .data
  text db `loop\n`
  textlen equ $ - text

section .text 
  global _start

_start:
  mov cl, 10
  OUTPUT: 
  mov rdi, 1
  mov rsi, text
  mov rdx, textlen
  mov rax, 1
  push rcx
  syscall 
  pop rcx
  dec cl
  jnz OUTPUT
  
  mov rax, 60
  syscall

```
The counter is `rcx`, as i want the code to loop ten times, i moved `10` into `rcx`.

![](assets/posts/ASM/loop/loop1_1.png)


As the output from the syscall is stored in `rcx`, i stored its value on the stack before the syscall using `push rcx`. 

![](assets/posts/ASM/loop/loop1_2.png)

After the syscall is over and i want to retrieve `rcx` original value. i will use `pop rcx` to get the topmost value on the stack (`rcx` previous value) and move it into `rcx`. 

![](assets/posts/ASM/loop/loop1_3.png)

The stack no longer containing `10`:

![](assets/posts/ASM/loop/loop1_4.png)

Finally, `rcx` is decremented. As it is not `0`, JNZ does not trigger and it will loop. 

![](assets/posts/ASM/loop/loop1_5.png)
