## Introduction
This guide explains how to complete the fourth stage of TIS-100 AKA segment 22800

![menu](assets/posts/post17/post17_img1_menu.png)

## Segment 22800
The goal for this segment is:
1. Read values from `IN.A` and `IN.B`
2. Read a value from `IN.S`
3. Write `IN.A` when `IN.S` =`-1`
4. Write `IN.B`when `IN.S` = `1`
5. Write `IN.A` + `IN.B` when `IN.S` = `0`

## Explanation:

### command node 3

```bash
S: MOV UP, ACC
   JGZ Z
   JLZ Y
   MOV LEFT, ACC
   ADD RIGHT
   JMP S
Z: MOV RIGHT, DOWN
   MOV LEFT, NIL
   JMP S
Y: MOV LEFT, DOWN
   MOV RIGHT, NIL
```

S:
1. Moves the value from `port UP` to the `ACC`
2. If the value of the `ACC` is greater than zero, run the set of instructions belonging to label `Z`
3. If the value of the `ACC` is lesser than zero, run the set of instructions belonging to label `Y`
4. Move the value from `port LEFT` to the `ACC` 
5. Add the value from `port RIGHT` to the `ACC`

Z:
1. Moves the value from `port RIGHT` to `port DOWN`
2. Moves the value from `port LEFT` to `NIL`. This prevents the value from `port LEFT` used being one from the previous cycle.
3. Go to the first line of instructions belonging to label `S`

Y:
1. Moves the value from `port LEFT` to `port DOWN`
2. Moves the value from `port RIGHT` to `NIL`. This prevents the value from `port RIGHT` used being one from the previous cycle.

`JMP S` was not used for `Y` as the code is already going to start over from the first line of instructions which is `S`.

### command node 2

```bash
MOV UP, RIGHT
```

1. This moves the value from `port UP` to `port RIGHT` which is command node 3's `port LEFT`

### command node 4

```bash
MOV UP, LEFT
```

1. This moves the value from `port UP` to `port LEFT` which is command node 3's `port RIGHT`
