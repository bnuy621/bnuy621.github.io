## Introduction
This post serves as a guide on solving TIS-100 first stage. 

## Why
I bought this game as i wanted to learn the basics of assembly.

## Download the PDF
Upon booting up the game for the first time, you are told to download a PDF which contains the guide for this game.

## Stage 1
The goal for stage 1 is simple being to move a value from `IN.X` `OUT.X` and `IN.Y` to `OUT.Y`:
![stage 1 overview](assets/posts/post12/post12_img1_stage1.png)

## Interpreting it
The first line on the command node for `IN.X` is:

```bash
MOV UP, DOWN
```
This means take the value from the port UP and move it to port DOWN. You can interpret it as `move value from UP to DOWN`. This is similar to assembly such as moving a value from one register to another <https://www.tutorialspoint.com/assembly_programming/assembly_registers.htm>:

```bash
mov	edx,len  ;message length
```

This is also explained on the guide:
![MOV instructions](assets/posts/post12/post12_img2_MOVGUIDE.png)

## Solving the first part
We can see this same line was used for the 2 nodes below the top right command node which moves the value from `IN.X` to `OUT.X`. This solves the first half of the goal:
![solutions for part 1](assets/posts/post12/post12_img5_S1_part1sol.png)
