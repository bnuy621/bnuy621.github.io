## Introduction
This post covers the bare basics of kismet and how to get it up and running. This is also based off a previous guide. Link to their website <https://www.kismetwireless.net/>

## What is Kismet

![](assets/posts/post33/img1_kismet_icon.png)

Quoting from the makers of Kismet themselves, "Kismet is an open source sniffer, WIDS, wardriver, and packet capture tool for Wi-Fi, Bluetooth, BTLE, wireless thermometers, airplanes, power meters, Zigbee, and more. Kismet runs on Linux, macOS, and Windows (via WSL). Kismet can operate both headless as a standalone capture and WIDS system, or with a full modern web-based UI."

To put it simply, analyze all kinds of network traffic.

Kismet is NOT designed to be an attack tool such as `Aircrack-NG` and the `Wi-Fi Pineapple`.


## Installation
Before installing Kismet, ensure you have a compatible wifi adapter that supports monitor mode. Link to list of them: <https://www.cellstream.com/2024/03/25/a-list-of-usb-wi-fi-adapters-that-support-monitor-mode/>

Afterwards, install the corresponding driver for the chipset the adapter is using. This is very important as if you don't, you can't capture any network traffic. I also highly recommned using a linux operating system to run Kismet due to windows lacking any public drivers that enable monitor mode which means even if you have the hardware (AKA the adapter) you probably don't have the software to use it.

i know you can just install it as a package but i prefer this method instead.

### What i am using
1. raspperry pi OS (the latest) on a raspberry pi 4
2. TP-Link AC600 T2U plus v1.0

I chose this setup as it is portable. I will be following the installation guide for Linux and pasting the commands i used below for easier reference. Link to official installation guide here: <https://www.kismetwireless.net/docs/readme/installing/linux/>


### 1 - Updating raspberry pi 4's OS

Before installing anything, it is important to first upgrade/update the OS:

```bash
sudo apt update && sudo apt full-upgrade -y
sudo reboot
```

### 2 - Installing core dependencies

As I am using a Debian based system:

```bash
sudo apt install build-essential git libwebsockets-dev pkg-config \
zlib1g-dev libnl-3-dev libnl-genl-3-dev libcap-dev libpcap-dev \
libnm-dev libdw-dev libsqlite3-dev libsensors-dev libusb-1.0-0-dev \
libubertooth-dev libbtbb-dev libmosquitto-dev librtlsdr-dev
```

This too as i have no clue if i need it but i ran it anyways:

```bash
sudo apt install rtl-433
```

### 3 - Cloning the repo

Clone the Kismet github repo:

```bash
git clone https://www.kismetwireless.net/git/kismet.git
```

### 4 - Configure 

Configure kismet

```bash
cd kismet
./configure
```

### 5 - Compiling it

Compile:

```bash
make version
```

```bash
make
```
This can be sped up by adding `-j(no. of cores)`. Such as:

```bash
make -j2
```
As my pi 4 has only 4GB of ram, i will be using `-j2`. 
### 6 - Installing
From the website itself, "Generally, you should install Kismet as suid-root; Kismet will automatically add a group and install the capture binaries accordingly.
When installed suid-root, Kismet will launch the binaries which control the channels and interfaces with the needed privileges, but will keep the packet decoding and web interface running without root privileges."

Hence run:

```bash
sudo make suidinstall
```

### 7 - Adding your user to the kismet group

```bash
sudo usermod -aG kismet $(whoami)
```

Now `sudo reboot` to ensure your user is the `kismet` group. 


## Running kismet

Firstly, enter the `kismet` directory:

```bash
cd kismet
```
Secondly, start up Kismet:

```bash
kismet
```

![](assets/posts/post33/img2_kismet_term.png)


Upon running it for the first time, you will be prompted to create an account. Afterwards, you will be greeted by this dashboard:


![](assets/posts/post33/img3_kismet_dashboard.png)


## Selecting your data source
For now there is zero data on the dashboard as you have not selected your data source. To do so, click on the menu > `Data sources` > select the `wlan` (wireless local area network) you will be using and click `enable source` to start monitor mode on it.

![](assets/posts/post33/img4_kismetmenu.png)

![](assets/posts/post33/img5_kismetsources.png)

![](assets/posts/post33/img6_kismetselectsource.png)


Your dashboard will now be filled with information.

![](assets/posts/post33/img7_dashboardinfo.png)

To stop the flow of information you have to turn off monitor mode. To turn off monitor mode , go back to `Data sources` and click `close`:

![](assets/posts/post33/img8_disablesource.png)
