## Segment 31904
0. Sequences are zero terminated
1. Read a sequence from `IN`
2. Write the sum to `OUT.S`
3. Write the length to `OUT.L`


## My solution
![menu](assets/posts/post19/post19_img2_finsol.png)


## Explanation

### Command node 1

```bash
MOV RIGHT, ACC
JEZ X
MOV ACC, RIGHT
X: MOV ACC,NIL
```

1. Move value from `port RIGHT` into `ACC`
2. If the value of `ACC` equals zero, run `X`
3. Move value from `ACC` into `port RIGHT`

X:
1. Move value from `ACC` into NIL, hence 'deleting' it

Command node 1 serves as a temporary storage so that command node 2 can retrieve the value later on

![menu](assets/posts/post19/post19_img3_finsolP1.png)



### Command node 2
```bash
S: MOV UP,ACC
   MOV ACC, RIGHT
   MOV ACC, LEFT
   JEZ X
   SWP
   ADD LEFT
   SWP
   JMP S
X: SWP
   MOV ACC, DOWN
```

S:
1. Move value from `port RIGHT` into `ACC`
2. Move value from `ACC` into `port RIGHT` (command node 3)
3. Move value from `ACC` into `port LEFT` (command node 1)
4. If `ACC` equals `0` run `X`
5. Swap `ACC` with `BAK`
6. Add value from `port LEFT` (command node 1), this adds the value to the `ACC`
7. Swap `BAK` with `ACC` and stores the new value back into the `BAK`. This is to prevent the value from being altered by line 1 as the `ACC`'s value needs to be from `IN` so line 4 will work.
8. Go back to line 1 


X:
1. Swap `ACC` with `BAK`
2. Move value from `ACC` into `port DOWN`

![menu](assets/posts/post19/post19_img4_finsolP2.png)

### Command node 3

```bash
S: MOV LEFT, ACC
   JEZ A
   SWP
   ADD 1
   SWP
   JMP S
A: SWP
   MOV ACC, DOWN
```

S:
1. Move the value from `port LEFT` into `ACC`
2. If value of `ACC` is equal to zero, run `A`
3. Swap the value of `ACC` with the `BAK`. 
4. Add 1 to the `ACC`
5. Swap the value of the `BAK` with `ACC`
6. start from line 1 of `S`

X:
7. Swap the value of `ACC` with the `BAK`
8. Move the value of the `ACC` to `port DOWN`
