## Segment 32050
1. Read a value from `IN`
2. Compare value to previous value
3. Write `1` to `OUT` if difference is `10` or more
4. If difference is not `10` or more, write `0` instead
5. The first output is always 0

## Explanation

### Command node 2

```bash
S: MOV LEFT ACC
   JEZ 0
   SAV
   SUB RIGHT
   MOV ACC DOWN
   SWP
   MOV ACC RIGHT
   JMP S
0: MOV ACC DOWN
   MOV ACC RIGHT
```
S:
1. Move the value from `port LEFT` to the `ACC`
2. Run the instructions for `0` if the value of `ACC` is 0. Else, skip to next line
3. Save the current value in the `ACC` to the `BAK`
4. Subtract the value from `port RIGHT` from the `ACC`
5. Move the value in `ACC` to `port DOWN`
6. Swap the value of the `ACC` with the `BAK`. The value of the `ACC` is now the value of the current `IN`
7. Move this value from the `ACC` to `port RIGHT`
8. Go back to the first line of `S`

0:
1. Move the value of the `ACC` to `port DOWN`
2. Move the value of the `ACC` to `port RIGHT`


![final solution part 1](assets/posts/post23/post23_img3_solP1.png)


### Command node 3

```bash
MOV LEFT ACC
MOV ACC LEFT
```

1. Stores value from `port LEFT` (command node 2) into its `ACC`
2. Afterwards, it moves the value from its `ACC` to `port LEFT`. This allows `command node 1` to subtract it

![final solution part 1](assets/posts/post23/post23_img4_solp2.png)

### Command node 6

```bash
S: MOV UP ACC
   JLZ Z
   JEZ 0 
   JGZ X
Z: NEG
   JMP X
X: SUB 10
   JLZ Y
   MOV 1 DOWN
   JMP S
Y: MOV 0 DOWN
   JMP S
0: MOV ACC DOWN
```

S:
1. Move values from `port UP` to its `ACC`
2. If `ACC` is less than `0` , go to `Z`
3. If `ACC` is `0`, go to `0`
4. If `ACC` is greater than `0`, go to `X`

Z:
1. Negate `ACC` value. For example if the value is `-32`, it becomes `32`
2. Go to `X`

X:
1. Subtract `10` from `ACC`. 
2. If `ACC` is less than `0` meaning the difference is NOT greater than or equal to `10`, go to `Y`. If it is greater than or equal to `10`, go to the next line
3. Write `1` to `out`
4. Go to first line of `S` 

Y:
1. Write `0` to out
2. Go to first line of `S`

0:
1. Mov `ACC` down AKA moving `0` down.
