### Q1
How can you get this malware to install itself?
Run it via the command line with the following arguments `-in <password>`

### Q2
What are the command-line options for this program? What is the password requirement?
-cc, -re, -in, -c

Password requirement is 4 characters.

### Q3
How can you use OllyDbg to permanently patch this malware, so that it doesn’t require the special command-line password?

Force the subroutine to always return 1.
### Q4
What are the host-based indicators of this malware?

Based off IDA itself, another service will be installed with the name of the binary. The binary will also copy itself to `%Systemroot%/System32` directory.

Registry key `SOFTWARE\\Microsoft \\XPS\\Configuration` being present.

### Q5
What are the different actions this malware can be instructed to take via the network?
CMD - run a command and send the output. SLEEP - sleep for X seconds. NOTHING - do nothing. UPLOAD - a file is uploaded to the infected computer. DOWNLOAD - a file is downloaded from the host's computer.

### Q6
Are there any useful network-based signatures for this malware?
Network traffic to `https://www.practicalmalwareanalysis.com`
