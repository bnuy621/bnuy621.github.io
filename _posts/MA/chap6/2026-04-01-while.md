## Introduction
Comparison of code in C vs how in looks in Assembly. Im using Linux with gcc compiler so it might look a bit different on your side.

## Original code

### C

```bash
#include <stdio.h>

int main(void) {
    int count = 1;

    while (count <= 5) {
        printf("count = %d\n", count);
        count++;
    }

    return 0;
}
```

## Explanation
Firstly, the local variable `count` is initialised at a negative offset, afterwards it is assigned the value `1`:

![](assets/posts/MA/chap6/post11/pt1.png)

Secondly, `count` is compared against `5`. If it is less than `5` it will take the `green` path by going to `loc_140001556`:

![](assets/posts/MA/chap6/post11/pt2.png)

At `loc_140001556`, it will display the message `count = %d` with `%d` being `count`'s value. This is followed with `count` being incremented by `1`. Afterwards it will loop back to `loc_14000156B`.

If `count` is larger than `5`, the while loop will end.
