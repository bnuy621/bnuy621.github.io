## Introduction 
Comparison of code in C vs how in looks in Assembly. Im using Linux with gcc compiler so it might look a bit different on your side.

## Original code

### C

```bash
#include <stdio.h>

int main(void) {
    int i;
    for (i = 0; i < 100; i++) {
        printf("i equals %d\n", i);
    }
    return 0;
}
```

### Explanation
Firstly, we can see here that the variable `i` is initialised with the value `0` assigned to it:

![](assets/posts/MA/chap6/post7/part1.png)

Afterwards the code goes to `loc_14000156B`. At `loc_14000156B` it is compared to 99 , if it is less or equal to `99` it moves to `loc_140001556` indicated by the green arrow:

![](assets/posts/MA/chap6/post7/part2.png)

At `loc_140001556` , `printf` is called to display the string `i equals %d` with `%d` being the value of i. Afterwards, i  is incremented by `1` and is looped back to `loc_14000156B` as seen with the blue arrow pointing back to it.

![](assets/posts/MA/chap6/post7/part3.png)

When `i` becomes `100` , it will no longer be lesser or equal to `99`, hence the loop will end:

![](assets/posts/MA/chap6/post7/part4.png)
