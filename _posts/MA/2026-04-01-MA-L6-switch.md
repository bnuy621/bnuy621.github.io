## Introduction
We will be observing what happens when you use switch.

## Original code

### C

```bash
#include <stdio.h>

int main(void) {
    int key = 2;

    switch (key) {
        case 1:
            printf("Case 1: one\n");
            break;
        case 2:
            printf("Case 2: two\n");
            break;
        case 3:
            printf("Case 3: three\n");
            break;
        default:
            printf("Default case: no match\n");
            break;
    }

    return 0;
}

```

## Explanation
Firstly, `key` is a local variable, it is initialised with a negative offset. Afterwards it is assigned the value `2`:

![](assets/posts/MA/post9/pt1.png)

Secondly, it is compared to the value `3` for `case 3`. If it matches, it will display `Case 3: three`:

![](assets/posts/MA/post9/case3.png)

If it does not pass the check, `key` is checked to ensure its value is not greater than 3. If it is, it will go to the `default` case immediately. This is to save time checking a value that will not match `1` or `2`.

![](assets/posts/MA/post9/casedefault.png)


Thirdly, it is compared to the value `1` for `case 1`. If it matches, it will display `Case 1: one` :

![](assets/posts/MA/post9/case1.png)

Else, it will be compared to the value `2`. If it matches, it will display `Case 2: two`: 

![](assets/posts/MA/post9/case2.png)

Lastly, if it does not match `2`, it will proceed to the default case. This is possible despite the check if it was a negative number.
