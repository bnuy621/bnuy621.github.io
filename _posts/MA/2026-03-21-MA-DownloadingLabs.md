## Introduction
How to get the lab exercises for "Practical Malware analysis"

![malware analysis book cover](assets/posts/post27/post27_img1_cover.png)

## Go to the Github repo
<https://github.com/mikesiko/PracticalMalwareAnalysis-Labs/tree/master>

![malware analysis lab repo](assets/posts/post27/post27_img2_repo.png)


Download the first 2 items `PracticalMalwareAnalysis-Labs-Windows7.7z` and `PracticalMalwareAnalysis-Labs.7z`. 


## Extract the zip files
Afterwards extract them via 7zip, the password for the zipped files is `malware`

## Results

One of the zipped files will contain an executable. After running it, your folder should contain this:

![malware analysis lab repo](assets/posts/post27/post27_img3_labfiles1.png)

Overwrite `10-01.sys` and `10-03.sys` with the ones from the other zipped file

![malware analysis lab repo](assets/posts/post27/post27_img4_labfiles2.png)
