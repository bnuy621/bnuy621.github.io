### Q1
What are this malware’s imports and strings?

![lab03-01.exe imports](assets/posts/MA/lab3/MA-lab3-1_img2_exe1imports.png)

![lab03-01.exe strings part 1](assets/posts/MA/lab3/MA-lab3-1_img3_exe1strings.png)

![lab03-01.exe strings part 2](assets/posts/MA/lab3/MA-lab3-1_img4_exe1string2.png)

Ans: Due to the abnormally low amount of imported functions, this malware is paceked. Its strings suggest at internet activity due to the URL `www.practicalmalwareanalysis.com`.  The strings `SOFTWARE\Microsoft\Windows\CurrentVersion\Run` and `SOFTWARE\Microsoft\Windows\CurrentVersion\Explorer\Shell Folders` suggests at registry key values being created/modified at these places.


### Q2
What are the malware’s host-based indicators?

![lab03-01.exe mutexes ](assets/posts/MA/lab3/MA-lab3-1_img5_exe1mutex.png)

![lab03-01.exe file written ](assets/posts/MA/lab3/MA-lab3-1_img6_exe1filewritten.png)

![lab03-01.exe file written ](assets/posts/MA/lab3/MA-lab3-1_img7_exe1reg.png)

Ans: A file `vmx32to64.exe` is created on the host. Secondly, a registry key value is written at `\REGISTRY\MACHINE\SOFTWARE\Microsoft\Windows\CurrentVersion\Run\VideoDriver`. 


### Q3
Are there any useful network-based signatures for this malware? If so, what are they?

![lab03-01.exe file written ](assets/posts/MA/lab3/MA-lab3-1_img8_exe1network.png)

Ans: Network traffic to `www.practicalmalwareanalysis.com` is a network-based signature for this malware.

### Q2
How would you get this malware to run after installation?

![lab03-02.exe strings ](assets/posts/MA/lab3/MA-lab3-2_img11_exe2strings.png)

Ans: Run it as a service via:
```bash
net start IPRIP
```

`IPRIP` was used as the strings extracted from this file suggests that it creates a service called `IPRIP`


### Q3

![lab03-02.exe process created](assets/posts/MA/lab3/MA-lab3-2_img12_exe2proccreated.png)

Ans: `svchost.exe` as it runs the service the malware installed
