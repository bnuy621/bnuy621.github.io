### Q6
What is the purpose of this malware?

The malware first checks for an internet connection which is carried out by `sub_401000` :

![](assets/posts/MA/lab6/6-2_Q6pt1.png)

If an active internet connection is present, the message `Success: Internet Connection` will be displayed else `Error 1.1: No Internet` will be displayed instead.

![](assets/posts/MA/lab6/6-2_Q6pt2.png)

If an active internet connection is present, it will proceed to `sub_401040` which uses the agent `Internet Explorer 7.5` when visiting the URL ``http://www.practicalmalwareanalysis.com/cc.htm`. 

![](assets/posts/MA/lab6/6-2_Q6pt3.png)

It will attempt to look for the HTML comment in the `cc.htm` file which contains a command. 

![](assets/posts/MA/lab6/6-2_Q6pt4.png)

If successful, it will proceed to `loc_40115C` . This command will be displayed in `Success: Parsed command is %c\n` with the command itself in it. 

![](assets/posts/MA/lab6/6-2_Q6pt5.png)


Lastly, it will go to sleep for `60000` miliseconds AKA one minute.

![](assets/posts/MA/lab6/6-2_Q6pt6.png)

To confirm it is 60000, right click on `0EA60h` and select base 10 which is the number system we are used to:

![](assets/posts/MA/lab6/6-2_Q6pt7.png)
